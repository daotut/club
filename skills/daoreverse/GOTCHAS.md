# daoreverse — грабли

## 1. Playwright не находится при `python3 -I`
**Симптом:** `ModuleNotFoundError: No module named 'playwright'`.
**Причина:** Playwright стоит в пользовательском site-packages (`~/Library/Python/3.x`), а `-I` его отключает.
**Решение:** `web-trace.py` запускать без `-I`, из нейтральной папки (`cd /private/tmp`), не из папки с
чужими файлами. Чужие скачанные скрипты интерпретатором не запускаются вообще — только читаются.

## 2. `tg://` роняет страницу в безголовом браузере
**Симптом:** после клика `navigate: chrome-error://chromewebdata/`, WebSocket закрывается сразу.
**Причина:** у Chromium нет обработчика `tg://`, и переход на deeplink заменяет страницу ошибкой.
`--stay` ловит только http(s)-переходы, кастомные схемы мимо `route`.
**Решение:** всё, что важно до ухода, видно в фазе клика (запросы, ответы, открытие сокета). Кадры сокета
после ухода в мессенджер не снимаются — механику дочитывать по коду и помечать «вывод».

## 3. WebSocket нет в HAR
Playwright не пишет WS в HAR. `web-trace.py` ловит их сам (`page.on("websocket")`): открытие — в
`requests.jsonl`, кадры — в `navigations.json` (`ws-sent` / `ws-received`).

## 4. `rg` не видит скрытые папки
Сборщики кладут код в `.webpack/`, `.vite/`; `rg` по умолчанию их пропускает. Всегда `rg -uu`. (из leanrea)

## 5. zsh и `echo ===`
Голое `==x` в zsh — подстановка пути к команде, `echo ====` падает с `=== not found`. Маркеры только в
кавычках: `echo '--- имя'`.

## 6. `rg` есть только внутри Claude Code
На Маке нет программы ripgrep: `rg` — функция оболочки Claude Code (`type rg` → shell function из
`~/.claude/shell-snapshots/`). В сессии Claude всё работает, в cron и в обычном терминале — нет.
Поэтому `rg` не в `requires`. Вне Claude: `grep -rEo '.{0,200}X.{0,200}'` (скрытые папки `grep` не
пропускает). Поставить настоящий — `brew install ripgrep`, с разрешения владельца компьютера.
